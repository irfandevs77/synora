# Synora

### A modern messaging and social communication platform.

Synora is a project focused on creating a simple, modern, and privacy-conscious communication experience.

## ✨ Features

### 💬 1-to-1 Chat
- Real-time messaging
- Message states
- Reply to messages
- Reactions
- Edit and delete messages
- Copy and forward messages

### 👥 Group Chat
- Create groups
- Add and remove members
- Group profiles
- Admin controls
- Permissions
- Shared media
- Pinned messages

### 🎨 Chat Customization
- Themes
- Wallpapers
- Mute chats
- Pin chats
- Archive chats

### 🔐 Privacy & Security
- Chat Lock
- Hidden Chats
- Online status controls
- Last seen controls
- Read receipts
- Typing indicators
- Block and report

## 🚀 Project Status

Synora is currently under active development.

More features and improvements are planned.

## 🎯 Vision

To build a modern communication platform with a strong focus on usability, customization, and privacy.

## 📌 Future Plans

- 📷 Image sharing
- 🎙️ Voice messages
- 🔎 Message search
- 🔒 Advanced privacy features
- ⚡ More customization options
